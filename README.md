# ASE Portfolio

Welcome to my Agentic Software Engineering Portfolio.

This repository contains my activities, learning experiences, and reflections about Agentic Software Engineering, artificial intelligence, and responsible AI development.

## Course Introduction

Agentic Software Engineering focuses on developing intelligent software systems that can perform tasks, make decisions, and solve problems with the help of artificial intelligence. This course introduces AI agents, Agile development, version control, and responsible AI.

## Personal Learning Goals

My goal in this course is to improve my understanding of artificial intelligence and how AI agents work in real-world applications. I also want to develop my programming and problem-solving skills, become more familiar with GitHub, and learn how to work effectively with other developers.

Most importantly, I want to understand how to create software that is not only functional but also safe, reliable, and responsible.

## Reflection from Part A

After completing Part A, I realized that Agentic Software Engineering is an important part of modern software development. AI agents can make applications more intelligent by allowing them to analyze information and perform tasks with less human assistance.

However, I also learned that these systems have limitations and possible risks. Developers must consider security, privacy, accuracy, and human supervision to ensure that AI is used properly and responsibly.
